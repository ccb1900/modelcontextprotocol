## 客户端详情

### 5ire

[5ire](https://github.com/nanbingxyz/5ire) 是一款开源跨平台桌面AI助手，支持通过MCP服务器使用工具。

**主要特性：**

- 内置MCP服务器可快速启用或禁用。
- 用户可通过修改配置文件添加更多服务器。
- 开源且用户友好，适合初学者。
- 未来将持续完善对MCP的支持。

### AgentAI

[AgentAI](https://github.com/AdamStrojek/rust-agentai) 是一个简化AI代理开发的Rust库，内置与MCP服务器的无缝集成。

[MCP服务器集成示例](https://github.com/AdamStrojek/rust-agentai/blob/master/examples/tools_mcp.rs)

**主要特性：**

- 多LLM支持——兼容主流LLM API（OpenAI、Anthropic、Gemini、Ollama及所有OpenAI API兼容服务）。
- 内置MCP服务器支持。
- 使用Rust这类内存安全语言构建类型安全的智能体流程。

### AgenticFlow

[AgenticFlow](https://agenticflow.ai/) 是一款无代码AI平台，可帮助构建7x24小时处理销售、营销和创意任务的智能体。通过MCP安全连接2500+个API和10000+个工具。

**主要特性：**

- 无代码创建AI智能体与工作流。
- 通过MCP访问10000+工具和2500+API的庞大资源库。
- 三步骤快速连接MCP服务器。
- 可随时安全管理连接并撤销访问权限。

**了解更多：**

- [AgenticFlow MCP集成](https://agenticflow.ai/mcp)

### AIQL TUUI

[AIQL TUUI] 是原生跨平台桌面AI聊天应用，支持MCP协议。兼容多AI服务商（如Anthropic/Cloudflare/Deepseek/OpenAI/Qwen）、本地AI模型（通过vLLM/Ray等）及聚合API平台（如Deepinfra/Openrouter等）。

**核心优势：**

- **动态LLM切换**：实时切换不同LLM API和智能体
- **全功能支持**：内置工具/提示词/资源/采样方法
- **可配置智能体**：通过设置灵活选择并自定义工具
- **高级采样控制**：调整参数并利用多轮采样优化结果
- **全平台兼容**：完美支持macOS/Windows/Linux
- **开源免费**：允许修改代码并自定义应用打包

**了解更多：**

- [TUUI文档](https://www.tuui.com/)
- [AIQL代码仓库](https://github.com/AI-QL)

### Amazon Q CLI

[Amazon Q CLI](https://github.com/aws/amazon-q-developer-cli) 是面向终端的开源智能编程助手。

**主要特性：**

- 完整支持MCP服务器
- 使用首选文本编辑器修改提示词
- 通过`@`快捷访问保存的提示词
- 直接在终端管理AWS资源
- 工具/配置/上下文管理/自动压缩等丰富功能

**快速开始**

```bash
brew install amazon-q
```

### Amazon Q IDE

[Amazon Q IDE](https://aws.amazon.com/q/developer) 是面向IDE的开源智能编程助手。

**主要特性：**

- 支持VSCode/JetBrains/Visual Studio/Eclipse等IDE
- 直接在IDE中管理AWS资源
- 通过IDE界面管理每个MCP工具的权限
### Apify MCP 测试工具  

[Apify MCP Tester](https://github.com/apify/tester-mcp-client) 是一个开源客户端，通过 Server-Sent Events (SSE) 连接任意 MCP 服务器。  
它是一个独立的 Apify Actor，专为通过 SSE 测试 MCP 服务器而设计，并支持授权头（Authorization headers）。  
该工具采用纯 JavaScript（传统风格）编写，托管于 Apify 平台，无需任何配置即可运行。  

**核心功能：**  

- 通过 SSE 连接任意 MCP 服务器。  
- 可与 [Apify MCP Server](https://apify.com/apify/actors-mcp-server) 配合使用，以与一个或多个 Apify [Actors](https://apify.com/store) 交互。  
- 根据上下文和用户查询动态调用工具（若服务器支持）。  

### Amp  

[Amp](https://ampcode.com) 是 Sourcegraph 开发的智能编码工具，支持 VS Code（以及兼容的衍生版本如 Cursor、Windsurf 和 VSCodium）和命令行运行。它还支持多人协作——您可以共享线程并与团队协同工作。  

**核心功能：**  

- 精细控制可用工具及权限  
- 支持在 VS Code 的 `mcp.json` 中定义的 MCP 服务器  

### Augment Code  

[Augment Code](https://augmentcode.com) 是一个 AI 驱动的编码平台，适用于 VS Code 和 JetBrains，提供自主代理、聊天和代码补全功能。本地与远程代理均具备完整的代码库感知能力，并原生支持 MCP，可通过外部源和工具增强上下文理解。  

**核心功能：**  

- 本地与远程代理全面支持 MCP。  
- 通过 MCP 服务器添加额外上下文。  
- 利用 MCP 工具自动化开发流程。  
- 兼容 VS Code 和 JetBrains 系列 IDE。  

### BeeAI 框架  

[BeeAI Framework](https://i-am-bee.github.io/beeai-framework) 是一个开源框架，用于大规模构建、部署和服务强大的智能代理工作流。该框架包含 **MCP 工具**，这是一个原生功能，可简化 MCP 服务器与代理工作流的集成。  

**核心功能：**  

- 无缝将 MCP 工具融入代理工作流。  
- 快速从已连接的 MCP 客户端实例化框架原生工具。  
- 计划未来支持代理式 MCP 功能。  

**了解更多：**  

- [在代理工作流中使用 MCP 工具的示例](https://i-am-bee.github.io/beeai-framework/#/typescript/tools?id=using-the-mcptool-class)  

### BoltAI  

[BoltAI](https://boltai.com) 是一款原生一体化 AI 聊天客户端，支持 MCP。它兼容多种 AI 服务提供商（OpenAI、Anthropic、Google AI 等），并支持本地 AI 模型（通过 Ollama、LM Studio 或 LMX 运行）。
