---
title: "提示模板"
description: "创建可复用的提示模板与工作流程"
---

提示模板使服务端能够定义可复用的提示模板和工作流，客户端可以轻松将其呈现给用户和大语言模型(LLM)。这为标准化和共享常见的LLM交互提供了强大方式。

<Note>

提示模板设计为**用户可控**，即服务端向客户端暴露这些模板时，预期用户能够明确选择使用它们。

</Note>

## 概述

MCP中的提示模板是预定义的模板，能够：

- 接收动态参数
- 包含来自资源的上下文
- 串联多个交互步骤
- 引导特定工作流程
- 呈现为UI元素（如斜杠命令）

## 提示结构

每个提示模板的定义包含：

```typescript
{
  name: string;              // 提示模板的唯一标识符
  description?: string;      // 人类可读的描述
  arguments?: [              // 可选的参数列表
    {
      name: string;          // 参数标识符
      description?: string;  // 参数描述
      required?: boolean;    // 参数是否必填
    }
  ]
}
```

## 发现提示

客户端可通过发送`prompts/list`请求发现可用提示：

```typescript
// 请求
{
  method: "prompts/list";
}

// 响应
{
  prompts: [
    {
      name: "analyze-code",
      description: "分析代码以寻找改进点",
      arguments: [
        {
          name: "language",
          description: "编程语言",
          required: true,
        },
      ],
    },
  ];
}
```

## 使用提示

要使用提示模板，客户端需发起`prompts/get`请求：

````typescript
// 请求
{
  method: "prompts/get",
  params: {
    name: "analyze-code",
    arguments: {
      language: "python"
    }
  }
}

// 响应
{
  description: "分析Python代码以寻找改进点",
  messages: [
    {
      role: "user",
      content: {
        type: "text",
        text: "请分析以下Python代码的改进空间：\n\n```python\ndef calculate_sum(numbers):\n    total = 0\n    for num in numbers:\n        total = total + num\n    return total\n\nresult = calculate_sum([1, 2, 3, 4, 5])\nprint(result)\n```"
      }
    }
  ]
}
````

## 动态提示

提示模板支持动态特性，可包含：
### 嵌入式资源上下文

```json
{
  "name": "analyze-project",
  "description": "分析项目日志与代码",
  "arguments": [
    {
      "name": "timeframe",
      "description": "需要分析的日志时间范围",
      "required": true
    },
    {
      "name": "fileUri",
      "description": "待审查代码文件的URI",
      "required": true
    }
  ]
}
```

处理 `prompts/get` 请求时：

```json
{
  "messages": [
    {
      "role": "user",
      "content": {
        "type": "text",
        "text": "请分析这些系统日志和代码文件是否存在问题："
      }
    },
    {
      "role": "user",
      "content": {
        "type": "resource",
        "resource": {
          "uri": "logs://recent?timeframe=1h",
          "text": "[2024-03-14 15:32:11] 错误：network.py第127行连接超时\n[2024-03-14 15:32:15] 警告：正在重试连接（第2次/共3次）\n[2024-03-14 15:32:20] 错误：超过最大重试次数",
          "mimeType": "text/plain"
        }
      }
    },
    {
      "role": "user",
      "content": {
        "type": "resource",
        "resource": {
          "uri": "file:///path/to/code.py",
          "text": "def connect_to_service(timeout=30):\n    retries = 3\n    for attempt in range(retries):\n        try:\n            return establish_connection(timeout)\n        except TimeoutError:\n            if attempt == retries - 1:\n                raise\n            time.sleep(5)\n\ndef establish_connection(timeout):\n    # 连接实现代码\n    pass",
          "mimeType": "text/x-python"
        }
      }
    }
  ]
}
```

## 示例实现

以下是在MCP服务器中实现提示功能的完整示例：

<CodeGroup>

```typescript TypeScript
import { Server } from "@modelcontextprotocol/sdk/server";
import {
  ListPromptsRequestSchema,
  GetPromptRequestSchema,
} from "@modelcontextprotocol/sdk/types";

const PROMPTS = {
  "git-commit": {
    name: "git-commit",
    description: "生成Git提交信息",
    arguments: [
      {
        name: "changes",
        description: "Git差异或变更描述",
        required: true,
      },
    ],
  },
  "explain-code": {
    name: "explain-code",
    description: "解释代码工作原理",
    arguments: [
      {
        name: "code",
        description: "需要解释的代码",
        required: true,
      },
      {
        name: "language",
        description: "编程语言",
        required: false,
      },
    ],
  },
};

const server = new Server(
  {
    name: "example-prompts-server",
    version: "1.0.0",
  },
  {
    capabilities: {
      prompts: {},
    },
  },
);

// 列出可用提示
server.setRequestHandler(ListPromptsRequestSchema, async () => {
  return {
    prompts: Object.values(PROMPTS),
  };
});

// 获取特定提示
server.setRequestHandler(GetPromptRequestSchema, async (request) => {
  const prompt = PROMPTS[request.params.name];
  if (!prompt) {
    throw new Error(`未找到提示: ${request.params.name}`);
  }

  if (request.params.name === "git-commit") {
    return {
      messages: [
        {
          role: "user",
          content: {
            type: "text",
            text: `为以下变更生成简洁但描述性的提交信息:\n\n${request.params.arguments?.changes}`,
          },
        },
      ],
    };
  }

  if (request.params.name === "explain-code") {
    const language = request.params.arguments?.language || "未知";
    return {
      messages: [
        {
          role: "user",
          content: {
            type: "text",
            text: `解释这段${language}代码的工作原理:\n\n${request.params.arguments?.code}`,
          },
        },
      ],
    };
  }

  throw new Error("未找到提示实现");
});
```

```python Python
from mcp.server import Server
import mcp.types as types


# 定义可用提示
PROMPTS = {
    "git-commit": types.Prompt(
        name="git-commit",
        description="生成Git提交信息",
        arguments=[
            types.PromptArgument(
                name="changes",
                description="Git差异或变更描述",
                required=True
            )
        ],
    ),
    "explain-code": types.Prompt(
        name="explain-code",
        description="解释代码工作原理",
        arguments=[
            types.PromptArgument(
                name="code",
                description="需要解释的代码",
                required=True
            ),
            types.PromptArgument(
                name="language",
                description="编程语言",
                required=False
            )
        ],
    )
}
# 初始化服务器  
app = Server("example-prompts-server")  

@app.list_prompts()  
async def list_prompts() -> list[types.Prompt]:  
    return list(PROMPTS.values())  

@app.get_prompt()  
async def get_prompt(  
    name: str, arguments: dict[str, str] | None = None  
) -> types.GetPromptResult:  
    if name not in PROMPTS:  
        raise ValueError(f"未找到提示词: {name}")  

    if name == "git-commit":  
        changes = arguments.get("changes") if arguments else ""  
        return types.GetPromptResult(  
            messages=[  
                types.PromptMessage(  
                    role="user",  
                    content=types.TextContent(  
                        type="text",  
                        text=f"为以下变更生成简洁但描述性的提交信息:\n\n{changes}"  
                    )  
                )  
            ]  
        )  

    if name == "explain-code":  
        code = arguments.get("code") if arguments else ""  
        language = arguments.get("language", "Unknown") if arguments else "Unknown"  
        return types.GetPromptResult(  
            messages=[  
                types.PromptMessage(  
                    role="user",  
                    content=types.TextContent(  
                        type="text",  
                        text=f"解释这段{language}代码的工作原理:\n\n{code}"  
                    )  
                )  
            ]  
        )  

    raise ValueError("未找到提示词实现")  
```

## 最佳实践  

实现提示词时应注意:  

1. 使用清晰、描述性的提示词名称  
2. 为提示词和参数提供详细说明  
3. 验证所有必需参数  
4. 优雅处理缺失参数  
5. 考虑为提示模板添加版本控制  
6. 适当缓存动态内容  
7. 实现错误处理机制  
8. 记录预期的参数格式  
9. 考虑提示词的可组合性  
10. 使用多种输入测试提示词  

## 用户界面集成  

提示词可以通过以下方式呈现在客户端UI中:  

- 斜杠命令  
- 快捷操作  
- 上下文菜单项  
- 命令面板条目  
- 引导式工作流  
- 交互式表单  

## 更新与变更  

服务器可通过以下方式通知客户端提示词变更:  

1. 服务器能力: `prompts.listChanged`  
2. 通知: `notifications/prompts/list_changed`  
3. 客户端重新获取提示词列表  

## 安全注意事项  

实现提示词时应考虑:  

- 验证所有参数  
- 净化用户输入  
- 考虑实施速率限制  
- 实现访问控制  
- 审计提示词使用情况  
- 妥善处理敏感数据  
- 验证生成内容  
- 设置超时机制  
- 防范提示词注入风险  
- 记录安全要求
