[MCP检测器](https://github.com/modelcontextprotocol/inspector)是一款用于测试和调试MCP服务器的交互式开发者工具。虽然[调试指南](/legacy/tools/debugging)将检测器作为整体调试工具包的一部分进行了介绍，但本文档将详细探讨检测器的各项功能与特性。  

## 快速入门  

### 安装与基础用法  

检测器可直接通过`npx`运行，无需安装：  

```bash  
npx @modelcontextprotocol/inspector <命令>  
```  

```bash  
npx @modelcontextprotocol/inspector <命令> <参数1> <参数2>  
```  

#### 检测NPM或PyPi上的服务器  

从[NPM](https://npmjs.com)或[PyPi](https://pypi.org)启动服务器包的常见方式：  

<Tabs>  

  <Tab title="NPM包">  

```bash  
npx -y @modelcontextprotocol/inspector npx <包名称> <参数>  

# 示例  
npx -y @modelcontextprotocol/inspector npx @modelcontextprotocol/server-filesystem /Users/用户名/桌面  
```  

  </Tab>  

  <Tab title="PyPi包">  

```bash  
npx @modelcontextprotocol/inspector uvx <包名称> <参数>  

# 示例  
npx @modelcontextprotocol/inspector uvx mcp-server-git --repository ~/code/mcp/servers.git  
```  

  </Tab>  
</Tabs>  

#### 检测本地开发的服务器  

对于本地开发或通过代码库下载的服务器，常用检测方式为：  

<Tabs>  
  <Tab title="TypeScript">  

```bash  
npx @modelcontextprotocol/inspector node 路径/到/服务器/index.js 参数...  
```  

  </Tab>  
  <Tab title="Python">  

```bash  
npx @modelcontextprotocol/inspector \  
  uv \  
  --directory 路径/到/服务器 \  
  run \  
  包名称 \  
  参数...  
```  

  </Tab>  
</Tabs>  

请仔细阅读附带的README文件以获取最准确的操作指南。  

## 功能概览  

<Frame caption="MCP检测器界面">  
  <img src="/images/mcp-inspector.png" />  
</Frame>  

检测器提供以下与MCP服务器交互的功能：  

### 服务器连接面板  

- 可选择用于连接服务器的[传输方式](/legacy/concepts/transports)  
- 对于本地服务器，支持自定义命令行参数和环境变量  

### 资源标签页  

- 列出所有可用资源  
- 显示资源元数据（MIME类型、描述信息）  
- 支持资源内容检查  
- 可测试订阅功能  

### 提示模板标签页  

- 展示可用提示模板  
- 显示提示参数和描述  
- 支持使用自定义参数测试提示  
- 预览生成的消息  

### 工具标签页  

- 列出可用工具  
- 展示工具架构和描述  
- 支持使用自定义输入测试工具  
- 显示工具执行结果  

### 通知面板  

- 呈现服务器记录的所有日志  
- 显示从服务器接收到的通知  

## 最佳实践  

### 开发工作流  

1. 启动开发  
   - 用检测器启动服务器  
   - 验证基础连接性  
   - 检查能力协商  

2. 迭代测试  
   - 修改服务器代码  
   - 重新构建服务器  
   - 重连检测器  
   - 测试受影响功能  
   - 监控消息流  

3. 测试边界情况  
   - 无效输入  
   - 缺失提示参数  
   - 并发操作  
   - 验证错误处理与错误响应
