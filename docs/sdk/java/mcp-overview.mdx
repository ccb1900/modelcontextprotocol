## 功能  

- 支持以下功能的 MCP 客户端与服务器实现：  
  - 协议[版本兼容性协商](/specification/2024-11-05/basic/lifecycle/#initialization)  
  - [工具](/specification/2024-11-05/server/tools/)发现、执行及列表变更通知  
  - 基于 URI 模板的[资源](/specification/2024-11-05/server/resources/)管理  
  - [根节点](/specification/2024-11-05/client/roots/)列表管理与变更通知  
  - [提示词](/specification/2024-11-05/server/prompts/)处理与管理  
  - 支持 AI 模型交互的[采样](/specification/2024-11-05/client/sampling/)功能  
- 多种传输实现：  
  - 默认传输方式（包含在核心 `mcp` 模块中，无需外部 Web 框架）：  
    - 基于标准输入输出的进程间通信传输  
    - 基于 Java HttpClient 的 SSE 客户端传输（用于 HTTP SSE 客户端流）  
    - 基于 Servlet 的 SSE 服务器传输（用于 HTTP SSE 服务器流）  
  - 可选的 Spring 集成传输（适用于 Spring 框架用户）：  
    - WebFlux SSE 客户端与服务器传输（支持响应式 HTTP 流）  
    - WebMVC SSE 传输（基于 Servlet 的 HTTP 流）  
- 支持同步与异步编程范式  

<Tip>  

核心模块 `io.modelcontextprotocol.sdk:mcp` 提供了默认的 STDIO 和 SSE 客户端/服务器传输实现，无需依赖外部 Web 框架。  

Spring 专用传输作为可选依赖提供，方便使用 [Spring Framework](https://docs.spring.io/spring-ai/reference/api/mcp/mcp-client-boot-starter-docs.html) 的开发者。  

</Tip>
## 架构

该SDK采用分层架构设计，各层职责明确：

![MCP协议栈架构图](/images/java/mcp-stack.svg)

- **客户端/服务端层（McpClient/McpServer）**：均通过McpSession实现同步/异步操作，其中McpClient负责客户端协议操作，McpServer管理服务端协议操作。
- **会话层（McpSession）**：使用DefaultMcpSession实现类管理通信模式和状态。
- **传输层（McpTransport）**：处理JSON-RPC消息序列化/反序列化，具体实现包括：
  - 核心模块中的StdioTransport（标准输入输出）
  - 独立传输模块中的HTTP SSE传输（支持Java HttpClient、Spring WebFlux、Spring WebMVC）

[MCP客户端](/sdk/java/mcp-client)是模型上下文协议（MCP）架构中的核心组件，负责与MCP服务端建立并管理连接，实现协议的客户端部分。

![Java版MCP客户端架构图](/images/java/java-mcp-client-architecture.jpg)

[MCP服务端](/sdk/java/mcp-server)是模型上下文协议（MCP）架构的基础组件，为客户端提供工具、资源和能力支持，实现协议的服务端部分。

![Java版MCP服务端架构图](/images/java/java-mcp-server-architecture.jpg)

关键交互流程：

- **客户端/服务端初始化**：传输设置、协议兼容性检查、能力协商及实现细节交换
- **消息流转**：JSON-RPC消息处理（含验证）、类型安全响应处理及错误处理
- **资源管理**：资源发现、基于URI模板的访问、订阅系统及内容获取

## 依赖配置

在项目中添加以下Maven依赖：

<Tabs>
  <Tab title="Maven">

核心MCP功能：

```xml
<dependency>
    <groupId>io.modelcontextprotocol.sdk</groupId>
    <artifactId>mcp</artifactId>
</dependency>
```

核心`mcp`模块已包含默认的STDIO和SSE传输实现，无需额外Web框架支持。

若使用Spring框架并需要特定传输实现，可添加以下可选依赖：

```xml
<!-- 可选：基于Spring WebFlux的SSE客户端/服务端传输 -->
<dependency>
    <groupId>io.modelcontextprotocol.sdk</groupId>
    <artifactId>mcp-spring-webflux</artifactId>
</dependency>

<!-- 可选：基于Spring WebMVC的SSE服务端传输 -->
<dependency>
    <groupId>io.modelcontextprotocol.sdk</groupId>
    <artifactId>mcp-spring-webmvc</artifactId>
</dependency>
```

  </Tab>
    <Tab title="Gradle">

    核心MCP功能：

```groovy
dependencies {
  implementation platform("io.modelcontextprotocol.sdk:mcp")
  //...
}
```

    核心`mcp`模块已包含默认的STDIO和SSE传输实现，无需额外Web框架支持。

    若使用Spring框架并需要特定传输实现，可添加以下可选依赖：

    ```groovy
    // 可选：基于Spring WebFlux的SSE客户端/服务端传输
    dependencies {
      implementation platform("io.modelcontextprotocol.sdk:mcp-spring-webflux")
    }

    // 可选：基于Spring WebMVC的SSE服务端传输
    dependencies {
      implementation platform("io.modelcontextprotocol.sdk:mcp-spring-webmvc")
    }
    ```

  </Tab>
</Tabs>
### 物料清单 (BOM)

物料清单 (BOM) 声明了某个版本所依赖的所有组件的推荐版本。  
在应用的构建脚本中使用 BOM，可以避免手动指定和维护依赖版本。  
相反，你所使用的 BOM 版本会自动决定依赖项的版本。  
这还能确保你默认使用的是经过支持和测试的依赖版本，除非你选择覆盖它们。

将 BOM 添加到项目中：

<Tabs>
  <Tab title="Maven">

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>io.modelcontextprotocol.sdk</groupId>
            <artifactId>mcp-bom</artifactId>
            <version>0.10.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

  </Tab>

  <Tab title="Gradle">

```groovy
dependencies {
  implementation platform("io.modelcontextprotocol.sdk:mcp-bom:0.10.0")
  //...
}
```

Gradle 用户还可以利用 Gradle（5.0+）对 Maven BOM 的原生支持，通过声明依赖约束来使用 Spring AI MCP BOM。  
具体实现方式是在 Gradle 构建脚本的依赖部分添加一个 'platform' 依赖处理方法。  
如上代码片段所示，之后可以无版本声明地引入你希望使用的一个或多个 spring-ai 模块的 Starter 依赖项，例如 spring-ai-openai。

  </Tab>
</Tabs>

将版本号替换为你希望使用的 BOM 版本。

### 可用依赖项

以下是 BOM 管理的可用依赖项：

- 核心依赖项
  - `io.modelcontextprotocol.sdk:mcp` - 核心 MCP 库，提供基础功能和 API 用于实现 Model Context Protocol，包括默认的 STDIO 和 SSE 客户端及服务端传输实现。无需外部 Web 框架。
- 可选传输依赖项（适用于 Spring Framework 的便捷支持）
  - `io.modelcontextprotocol.sdk:mcp-spring-webflux` - 基于 WebFlux 的 Server-Sent Events (SSE) 传输实现，适用于响应式应用。
  - `io.modelcontextprotocol.sdk:mcp-spring-webmvc` - 基于 WebMVC 的 Server-Sent Events (SSE) 传输实现，适用于基于 Servlet 的应用。
- 测试依赖项
  - `io.modelcontextprotocol.sdk:mcp-test` - 为基于 MCP 的应用提供的测试工具和支持。
