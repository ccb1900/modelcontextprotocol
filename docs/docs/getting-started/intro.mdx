MCP 是一种开放协议，它标准化了应用程序如何向大型语言模型 (LLM) 提供上下文。你可以把 MCP 想象成 AI 应用的 USB-C 接口。正如 USB-C 为设备连接各种外设提供了标准化方式，MCP 为 AI 模型连接不同数据源和工具提供了标准化方案。通过 MCP，你可以在 LLM 之上构建智能体和复杂工作流，将你的模型与世界连接起来。

MCP 提供：

- **不断增长的开箱即用集成列表**，让你的 LLM 直接接入
- **标准化方法** 为 AI 应用构建自定义集成
- **开放协议** 任何人都可以自由实现和使用
- **灵活切换能力** 在不同应用间迁移时保持上下文连贯

## 准备构建？

MCP 提供多语言官方 **SDK**，查看 [SDK 文档](/docs/sdk) 为你的项目选择合适的开发工具包。这些 SDK 会处理协议细节，让你专注于功能开发。
