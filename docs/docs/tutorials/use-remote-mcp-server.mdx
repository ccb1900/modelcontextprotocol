远程MCP服务器将AI应用的能力从本地环境延伸至云端，提供对互联网托管工具、服务和数据源的访问权限。通过连接远程MCP服务器，您可以将AI助手从实用工具转变为具备实时访问外部资源能力的智能队友，能够处理复杂的多步骤项目。

目前众多客户端已支持远程MCP服务器，实现了广泛的集成可能性。本指南以[Claude](https://claude.ai/)为例演示连接方法——这是众多[支持MCP的客户端](/clients)之一。虽然我们重点介绍通过自定义连接器实现的Claude集成方案，但这些概念同样适用于其他兼容MCP的客户端。

## 理解远程MCP服务器

远程MCP服务器与本地服务器功能相似，但部署在互联网而非本地机器上。它们向Claude开放各类工具、提示词和资源，使其能代您执行任务。这些服务器可与项目管理工具、文档系统、代码仓库等任何支持API的服务集成。

远程MCP服务器的核心优势在于可访问性。不同于需要在每台设备安装配置的本地服务器，远程服务器可通过任何联网的MCP客户端访问。这使其特别适合：基于网页的AI应用、强调易用性的集成方案，以及需要服务端处理或认证的场景。

## 什么是自定义连接器？

自定义连接器是Claude与远程MCP服务器之间的桥梁。通过它们，您可以将Claude直接接入工作流中最关键的工具和数据源，使Claude能在您惯用的软件环境中运行，并从外部工具的完整上下文中获取洞察。

借助自定义连接器，您可以：
- [连接Claude至第三方开发者提供的现有远程MCP服务器](https://support.anthropic.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp)
- [构建专属远程MCP服务器来对接任意工具](https://support.anthropic.com/en/articles/11503834-building-custom-connectors-via-remote-mcp-servers)
## 连接远程MCP服务器

将Claude连接到远程MCP服务器的过程需要通过[Claude界面](https://claude.ai/)添加自定义连接器。这将建立Claude与所选远程服务器之间的安全连接。

<步骤>
<步骤标题="进入连接器设置">
在浏览器中打开Claude并进入设置页面。点击个人资料图标，从下拉菜单中选择"设置"。在设置中，找到并点击侧边栏的"连接器"选项。

这将显示当前已配置的连接器，并提供添加新连接器的选项。

</步骤>

<步骤标题="添加自定义连接器">
在连接器部分滚动到底部，找到"添加自定义连接器"按钮。点击此按钮开始连接流程。

<框架>
  <图片
    src="/images/quickstart-remote/1-add-connector.png"
    alt="Claude设置中的添加自定义连接器按钮"
  />
</框架>

随后会出现一个对话框，提示输入远程MCP服务器URL。该URL应由服务器开发者或管理员提供。输入完整URL，确保包含正确的协议(https://)和必要的路径组件。

<框架>
  <图片
    src="/images/quickstart-remote/2-connect.png"
    alt="输入远程MCP服务器URL的对话框"
  />
</框架>

输入URL后，点击"添加"继续连接过程。

</步骤>

<步骤标题="完成身份验证">
大多数远程MCP服务器需要身份验证以确保资源访问安全。验证方式因服务器实现而异，常见方式包括OAuth、API密钥或用户名/密码组合。

<框架>
  <图片
    src="/images/quickstart-remote/3-auth.png"
    alt="远程MCP服务器身份验证界面"
  />
</框架>

按照服务器提供的验证提示操作。可能会重定向到第三方验证服务提供商，或在Claude内显示验证表单。完成验证后，Claude将与远程服务器建立安全连接。

</步骤>

<步骤标题="访问资源和提示">
成功连接后，远程服务器的资源和提示将在Claude对话中可用。点击消息输入区的回形针图标打开附件菜单即可访问。

<框架>
  <图片
    src="/images/quickstart-remote/4-select-resources-menu.png"
    alt="显示可用资源的附件菜单"
  />
</框架>

菜单中会显示所有已连接服务器提供的资源和提示。选择要加入对话的项目，这些资源将为Claude提供来自外部工具的上下文信息。

<框架>
  <图片 src="/images/quickstart-remote/5-select-prompts-resources.png" alt="从菜单中选择特定资源和提示" />
</框架>
</步骤>

<步骤标题="配置工具权限">
远程MCP服务器通常会提供多个功能各异的工具。您可以通过连接器设置配置权限，控制Claude允许使用的工具，确保只执行明确授权的操作。

<框架>
  <图片
    src="/images/quickstart-remote/6-configure-tools.png"
    alt="工具权限配置界面"
  />
</框架>

返回连接器设置，点击已连接的服务器。在此可以启用或禁用特定工具、设置使用限制，并根据需要配置其他安全参数。

</步骤>
</步骤>
## 远程 MCP 服务器使用最佳实践

使用远程 MCP 服务器时，请遵循以下建议以确保安全高效的体验：

**安全注意事项**：连接前务必验证远程 MCP 服务器的真实性。仅连接来自可信来源的服务器，并仔细检查认证过程中请求的权限。对于敏感数据或系统的访问授权需保持谨慎。

**管理多个连接器**：您可以同时连接多个远程 MCP 服务器。建议按用途或项目分类管理连接器以保持条理性。定期清理不再使用的连接器，确保工作环境整洁安全。
