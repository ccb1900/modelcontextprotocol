## 入门指南

每个 SDK 提供相同的功能，但遵循各自语言的惯例和最佳实践。所有 SDK 均支持：

- 创建可暴露工具、资源和提示的 MCP 服务器
- 构建可连接任何 MCP 服务器的客户端
- 本地和远程传输协议
- 符合协议规范的类型安全实现

访问所选语言的 SDK 页面获取安装指南、文档和示例代码。
