## 智能体

随着 MCP 日益融入智能体工作流，我们正聚焦以下关键改进：

- **异步操作**：支持可能需要较长时间完成的长期运行操作，并实现断连与重连的弹性处理

## 认证与安全

我们正在升级授权与安全资源，以提升用户安全性并优化开发者体验：

- **指南与最佳实践**：以文档形式记录安全部署 MCP 的具体要求，帮助开发者规避常见陷阱
- **动态客户端注册(DCR)替代方案**：探索替代 DCR 的方案，在保持流畅用户体验的同时解决运营难题
- **细粒度授权**：为敏感操作开发基础授权机制与实施指南
- **企业托管授权**：新增企业级功能，通过单点登录(SSO)简化 MCP 服务器授权
- **安全授权引导**：支持开发者为下游 API 集成独立于主 MCP 服务器授权的安全认证流程

## 验证

为培育健康的开发者生态，我们计划投入：

- **参考客户端实现**：通过高质量 AI 应用演示协议特性
- **参考服务端实现**：展示认证模式与远程部署最佳实践
- **合规性测试套件**：自动验证客户端、服务端及 SDK 对规范的准确实现

这些工具将帮助开发者自信地实施 MCP，同时确保整个生态系统的行为一致性。

## 注册中心

为实现 MCP 的全部潜力，我们需要简化的服务器分发与发现机制。

我们计划开发[**MCP注册中心**](https://github.com/orgs/modelcontextprotocol/discussions/159)，提供集中化的服务器发现与元数据服务。该注册中心将主要作为 API 层，供第三方市场与发现服务进行扩展。

## 多模态

在 MCP 中全面支持 AI 能力，包括：

- **新增模态**：视频与其他媒体类型
- **[流式处理](https://github.com/modelcontextprotocol/specification/issues/117)**：支持多部分分块消息与双向通信，实现交互式体验
